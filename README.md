# Interview questions where every wrong answer is explained

Sixty free practice questions, twenty each for JavaScript, Python and SQL, playable at
https://thibaudlepan77-svg.github.io/interview-questions-verified/

Every snippet was run before its answer was written down, JavaScript on Node and Python on CPython, so the expected output is what the runtime printed. SQL queries had to return exactly the same rows on SQLite and on DuckDB, two engines with no shared code, or the question was thrown out. Each question comes with a short reason for every one of its four options.

The questions are a sample from three larger banks, 600 JavaScript, 600 Python and 502 SQL questions, sold as PDFs.

If an answer looks wrong to you, open an issue with the snippet number and what you get when you run it.
