What does print(s.str.startswith('a').tolist()) print? pandas Strings, Dates and apply

Block 8, Strings, Dates and apply, question 19 of the pandas sample

import pandas as pd
s = pd.Series(['apple', 'banana', 'avocado'])
print(s.str.startswith('a').tolist())

What does this print?

  1. A. [True, True, True]
  2. B. ['a', 'a']
  3. C. [True, False, True]
  4. D. [False, True, False]
Show the answer and why each option is right or wrong

Answer, C. [True, False, True]

A. [True, True, True]
Assumes startswith checks for the letter anywhere in the string instead of only at its very first position.
B. ['a', 'a']
Assumes startswith extracts the matching prefix itself instead of reporting a boolean for each row.
C. [True, False, True]
Correct. str.startswith checks only the first character of each string against 'a', which apple and avocado satisfy and banana does not.
D. [False, True, False]
Reports the exact opposite of each row, as if the check were for endswith or a negated condition.

str.startswith mirrors the built in str.startswith method, testing only the beginning of each string, and it returns one boolean per row rather than extracting any part of the text.

The answer above is what pandas 3.0.5 printed when the snippet was run, not what someone expected it to do.
