What does console.log(handle(new TimeoutError('late'))) print? JavaScript Errors, Control Flow and Sharp Edges

Block 8, Errors, Control Flow and Sharp Edges, question 7 of the JavaScript sample

class NotFoundError extends Error {}
class TimeoutError extends Error {}
function handle(err) {
  if (err instanceof NotFoundError) return 'missing';
  if (err instanceof TimeoutError) return 'slow';
  return 'unknown';
}
console.log(handle(new TimeoutError('late')));

What does this print?

  1. A. TimeoutError
  2. B. slow
  3. C. unknown
  4. D. missing
Show the answer and why each option is right or wrong

Answer, B. slow

A. TimeoutError
Confuses the return value with the constructor name of the error object passed in.
B. slow
Correct. instanceof checks the exact prototype chain of the passed object, and only the TimeoutError branch matches it.
C. unknown
Assumes instanceof only matches the base Error class and not user defined subclasses, but a class extending Error still satisfies instanceof for itself.
D. missing
Assumes both custom classes are indistinguishable subclasses of Error and the first branch always wins, but instanceof checks the specific prototype chain of the object being tested.

instanceof walks the prototype chain of the object and checks each link against the given constructor. A TimeoutError instance is only an instance of TimeoutError and Error, never of an unrelated sibling class.

The answer above is what the Node interpreter printed when the snippet was run, not what someone expected it to do.
